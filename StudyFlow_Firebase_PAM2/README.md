# StudyFlow — PAM 2 com Firebase

Comece pelo **GUIA_PAM2.md**: análise do projeto, modelo das coleções, configuração do console, instalação e testes.

Esta versão mantém as três telas originais e acrescenta Firestore, Authentication anônimo, CRUD de tarefas e histórico de planos de foco.

1. Configure Authentication e Firestore conforme o guia.
2. Publique o conteúdo de firestore.rules no console Firebase.
3. Copie .env.example para .env e preencha seus valores.
4. Execute npm install.
5. Execute npx expo start --web --clear.

Sem as configurações da sua conta, o aplicativo não conecta. O guia registra os limites de validação da entrega.
